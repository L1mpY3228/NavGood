NavGood помогает собрать нужные сайты, папки, программы и игры в одном удобном месте. Создавай группы, например «Игры», «Работа» или «Полезное», и быстро открывай нужный ярлык через боковую панель.

Возможности
Ярлыки на сайты, локальные папки, файлы и игры.
Группы ярлыков и боковая панель для навигации.
Автоматический поиск favicon для веб-сайтов; можно назначить свою иконку.
Несколько тем оформления, настройка шрифта и цветов.
Запуск игровых URI, если соответствующий лаунчер установлен в Windows.
Необязательное меню «Запрет» с 12 BAT-вариантами из Zapret Roblox 1.9.8. Архив загружается только по нажатию пользователя и проверяется по SHA-256; скрипты не запускаются при загрузке автоматически.
Как получить NavGood
Скачайте NavGood.exe из раздела Releases, сохраните его на компьютере и запустите двойным щелчком. Python для запуска готового EXE не требуется.

NavGood хранит группы, настройки и ярлыки локально в профиле пользователя Windows (%USERPROFILE%\.link_shortcuts). Поэтому при получении EXE другого пользователя ваши личные ярлыки ему не передаются.

Важно
Запуск локальных файлов, игр и игровых URI зависит от ассоциаций Windows и установленных лаунчеров.
